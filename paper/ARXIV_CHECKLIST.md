# arXiv checklist (first-time author)
1. Create an arXiv account with your real name and affiliation (Trident or "Independent researcher").
2. Category cs.CL. First-time submitters need an endorsement: ask an author of a relevant cs.CL paper (a co-author or research-community contact) BEFORE you finish the paper, since arXiv issues the request link at submission.
3. Compile main.tex to PDF; arXiv takes the .tex source, figures and .bbl. Include the repo link and the dataset link.
4. Fill every bracket. Remove "PREPRINT" only never; keep the word, it is true.
5. Use Zenodo for a dataset DOI and cite it. Tag a GitHub release matching the paper version.
6. If the paper uses AI-drafted translations or seeds, say so in the data statement (mt_system field) and name your post-editing.
